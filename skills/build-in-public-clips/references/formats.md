# Formats

**Tutorial outline (YouTube).** Searchable title. Cold open on the result. The problem. The steps with timestamps. What broke. What to try. Link to the list or workshop.

**Short (30 to 60 seconds).**
- Seconds 0 to 3: the result on screen or the problem stated. Text on screen.
- Middle: the turn, in real footage.
- End: what happened, one line pointing to the list or workshop.
- Write for sends: something a person would forward to a friend with the same problem.

**Carousel (6 to 8 slides).** Slide 1 states the problem. One step per slide, using a real screenshot. Last slide: what it produced, and where to go next.

**Screen safety.** Check for API keys, tokens, `.env` files, emails, client names, invoices, browser tabs and notifications. List the timestamp of each, so the user can cut or re-record the part.

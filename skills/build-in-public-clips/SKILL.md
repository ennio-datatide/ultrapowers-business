# Build in Public Clips

You turn one real working session into one tutorial outline, three Shorts scripts and one carousel. Keep it raw: real errors, real screens, real time. Originality is ranked, and founder-made recordings tend to beat polished or AI-made content.

## Before Starting

Read `.agents/product-marketing-context.md` and `.agents/brand-voice.md` if they exist. Get the recording transcript with timestamps. If there are no timestamps, say so and refer to moments by quote.

## Workflow

1. **Find the moments.** Read the whole transcript. List each moment that has a problem, a turn and a visible result. Mark surprises and failures.
2. **Check what is on screen.** List anything to remove before publishing: keys, tokens, client data, private names. See `references/formats.md`.
3. **Pick.** One through-line for the tutorial, and three separate moments for Shorts, each understandable alone.
4. **Write.** Follow the formats in `references/formats.md`. Every line must trace to something that happened.
5. **Route.** Every piece points to the email list or the free workshop.

## Rules

- Use only what happened in the session. Never add a result, a time or a number that is not in the transcript.
- Keep the failure in. If the first try broke, show it.
- Capability claims must match what the recording proves.
- No income claims, and no em dashes or en dashes.

## Output Format

1. Moments table: timestamp or quote, what happens, why it works.
2. Tutorial outline.
3. Three Shorts scripts.
4. Carousel, slide by slide.
5. Screen safety list.
